I want to create a Telegram bot
This can be run locally on this computer for now
The idea: 
My family has a Telegram group
A member posts a message about expenses
for example "Products Spar /n 1500" - which means that 1500 <default currency> was spent on Products

when a report for a specific month is requested - the bot should be able to
1. read messages for the specific month
2. generate a context for the LLM API for a monthly report on which category, how much was spent (Categories are still primitive)
3. Correctly handling the currency (if it is not specified - take the default currency)
4. Send a request to the LLM API (for now I don't want to be tied to a specific LMM, so I would like it to be an abstraction over: OpenAI (some cost effective) & Monosnap (Kimi 2.7))
5. Process the response and send me a response
6. Save/edit state/settings e.g. prefered categories, default currency, output currency/currencies
7. Save the report (by month) for Future comparsion

on bot initialization
1. setup currencies: default and report output
2. setup default categories or allow LLM chose them
3. optionally: set the <Store/Place Name - category> map and save it (for more deterministic mapping)
